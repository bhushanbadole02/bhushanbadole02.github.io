Security & ML 01

Cryptocurrency Transaction Security Using Behavioral Biometrics

Engineered a behavioral biometrics authentication pipeline to secure cryptocurrency wallet transactions by modeling user interaction patterns such as keystroke dynamics and mouse/session velocity. Extracted temporal and statistical behavioral features to train anomaly detection and classification models capable of flagging unauthorized transaction attempts in real time.

Python Scikit-learn PyTorch Anomaly Detection
Federated Learning & IoT Security 02

Federated Learning Approaches for IoT Intrusion Detection

Architected a privacy-preserving distributed Intrusion Detection System (IDS) using Deep Neural Networks trained across decentralized IoT client nodes on the CICIoT2023 benchmark dataset. Evaluated and benchmarked FedAvg and FedProx aggregation strategies under both IID and Non-IID data partitions to mitigate client drift and improve attack classification stability.

Python PyTorch Flower CICIoT2023
Deep Learning & Desktop App 03

Recommendation Of Farming Equipment Using Deep Learning

Developed a standalone desktop recommendation application that matches optimal agricultural machinery to farm conditions using a Convolutional Neural Network (CNN) inference engine. Built a multi-parameter preprocessing pipeline integrating soil type, crop variety, field dimensions, weather conditions, and historical equipment performance data.

Python TensorFlow CNN Desktop Application
